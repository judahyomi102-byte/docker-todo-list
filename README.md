# Docker To-Do List Application

A simple To-Do List application built using Python, Flask and Docker.

## Features
- Add tasks
- View tasks
- Mark tasks as completed
- Delete tasks

## Technologies
- Python
- Flask
- Docker
- Docker Compose

## How to Run
1. Install Docker.
2. Open the project folder in a terminal.
3. Run `docker compose up --build`.
4. Visit http://localhost:5000 in your browser.
